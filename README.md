# 壳里 · 女性安全地图

壳里把酒店位置、周边环境、公开证据和房间照片检查组织成一套分层的安全决策工具。这个仓库是可独立部署的网页作品集版本，默认使用仓库内的数据快照，当前覆盖上海、贵阳和西双版纳。

## 当前产品形态

- 腾讯地图上的酒店风险分布与城市切换
- 酒店搜索、风险筛选、排序和详情抽屉
- 环境初评、深度审计状态、证据与维度评分
- 本地收藏、最近查看和默认筛选偏好
- 服务端 DeepSeek 环境初评，不在浏览器暴露 API Key

酒店安全结果用于辅助筛选，不替代入住前的现场判断。“待补充”表示酒店已收录，但还没有足够信息形成安全初评。

## DeepSeek 环境初评

详情页会把已采集的周边 POI 发送到 `/api/environment-assessment`。服务端先计算可解释的规则基线，再调用 DeepSeek，最终按以下方式融合：

- 规则基线 45%：公安、医疗、交通和便利设施作为正向信号，夜生活密度和道路偏僻风险作为负向信号。
- DeepSeek 判断 55%：只分析 POI 的距离、密度和类别组合，输出模型分、因素、摘要和置信度。
- 最终置信度取模型置信度和数据覆盖度中的较低值，避免少量 POI 造成虚假确定性。
- 环境初评只表示“周边地图环境”，不评价酒店内部管理，也不把缺少数据解释为没有风险。

接口密钥只读取服务端环境变量：

```bash
cp .env.example .env.local
# 填写 DEEPSEEK_API_KEY 后运行
npx vercel dev
```

默认模型为 `deepseek-v4-flash`，可通过 `DEEPSEEK_MODEL` 切换。静态 GitHub Pages 仍可浏览地图和快照数据；需要实时 DeepSeek 初评时，请部署到支持 `/api` Serverless Functions 的环境（例如 Vercel），或通过 `window.API_BASE` 指向已部署的后端。跨域部署时用 `ALLOWED_ORIGINS` 配置允许访问的网页域名（多个域名用逗号分隔）。

## 数据流

1. `data/cities.json` 与 `data/hotels-*.json` 提供地图列表快照。
2. `data/details/{hotel_id}.json` 提供酒店、公开证据、环境 POI 与维度评分。
3. 用户主动点击“生成最新初评”后，浏览器只上传当前酒店基础信息与环境 POI。
4. 服务端生成 POI 画像和规则基线，调用 DeepSeek，并对结构化结果进行校验、截断和分值融合。
5. 返回值只在详情页展示；是否持久化到正式数据库由生产后端决定。
